# Flexbox Navbar References

A set of **four responsive navigation bar references** built using **HTML5 and CSS3**, with layouts powered entirely by **CSS Flexbox**.

This project was created as a **personal reference library** — a collection of base navbar setups that can be quickly reused, adapted, or expanded for future projects.

---

## 📌 Project Overview

Each navbar example demonstrates a slightly different layout or styling approach while maintaining a clean, flexible structure. The focus of this project is:

- Semantic HTML5 structure
- Flexbox-based layout alignment
- Reusable and readable CSS
- Consistent naming conventions
- Simple, extensible design patterns

These examples are intentionally kept framework-free to serve as a solid foundation for both small and large projects.

---

## 🧰 Technologies Used

- **HTML5**
- **CSS3**
  - Flexbox
  - Custom button styling
  - Hover and transition effects

No JavaScript or external frameworks are required.

---

## 🎯 Purpose

- Serve as a **quick reference** for Flexbox-based navbar layouts
- Provide a **base setup** for new projects
- Help maintain consistency across different UI implementations
- Act as a sandbox for experimenting with layout ideas

---

## 🚀 Usage

You’re free to:

- Copy any navbar setup into a new project
- Modify colors, spacing, or typography
- Extend layouts with dropdowns, mobile menus, or JavaScript behavior

Each example is self-contained and easy to customize.

---

## 📝 Notes

- These navbars are desktop-first by design.
- Mobile responsiveness can be added using media queries as needed.
- Class naming follows a predictable, readable pattern for maintainability.
